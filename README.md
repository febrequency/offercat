# 秋招 Tracker 初版模块

这是一个本地可运行的秋招信息 tracker 原型，先聚焦最小可用功能：

- 记录公司、岗位、行业、城市、截止时间、投递链接和 JD
- 按关键词、行业、投递状态筛选岗位
- 查看岗位详情和 JD 原文
- 自动从 JD 中识别一批常见技能关键词
- 维护投递状态看板
- 给岗位添加简单面试记录
- 记录腾讯文档信息源，并支持 CSV / 复制表格内容导入
- 数据暂存在浏览器本地，不需要后端和数据库

## 如何打开

直接用浏览器打开 `index.html` 即可。

## 如何从腾讯文档导入

1. 打开网页里的“信息源”页面。
2. 打开对应腾讯文档。
3. 优先选择导出 CSV；如果不方便导出，就复制表格区域。
4. 回到网页，把 CSV 文件上传，或把复制的表格内容粘贴到导入框。
5. 点击“导入到岗位库”。

程序会尽量识别这些列名：公司、岗位、行业、城市、地点、链接、投递入口、截止时间、JD、要求、备注。

## 腾讯文档自动同步探针

当前已经验证可以从部分腾讯文档的 `opendoc` 数据口读取并解压出表格文本。运行：

```bash
node scripts/probe-tencent-doc.mjs
```

会输出文档标题、表格尺寸，以及从工作簿中抽取到的表头、企业名称、城市、截止时间等样例字段。

## 官网自动巡检

公司官网源维护在：

```txt
data/company-sources.json
```

运行巡检：

```bash
node scripts/sync-official-careers.mjs
```

脚本会逐个访问公开招聘官网，查找 `2027`、`27届`、`校招`、`校园招聘`、`应届`、`提前批`、`实习` 等信号，并输出到：

```txt
data/synced-official-jobs.json
```

回到网页的“数据源”页，点击“导入官网巡检结果”，就能把这些官网信号导入岗位库。

当前这版是轻量官网巡检器：能发现官网上的校招信号和相关链接。要抓到完整岗位列表，需要继续为字节、腾讯、美团、华为等官网补专属 adapter。
